# Changelog

## 1.0.0

* First release as a `select_one` field plug-in.
* Stores the dropped piece's choice value, right or wrong; special codes 96 and 97 for the enumerator.
* Plug-in metadata log (attempts, sequence, times, piece order).
* Animations, synthesized sounds, five themes, practice mode with hand demo.
* Tablet-first layout (side by side in landscape, stacked in portrait).
* Offline puzzle maker and a three-puzzle sample form.
